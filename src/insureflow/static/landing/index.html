Zero Token Architecture

The best token is the one you never had to generate.

Before any pipeline stage spends a token, Rytera asks: can code, rules, or a trained model solve this deterministically? Most of underwriting can. LLM calls are the exception, not the rule — and every one is budgeted, tracked, and reported in each job's zta_report.

Layer 1

Deterministic code

Parsers, provenance, reconciliation, COPE, rating engines, and compliance rules solve everything they can — with zero tokens and full reproducibility.

0 tokens · 100% reproducible
Layer 2

Trained ML

Eight gradient-boosted models score loss, fraud, churn, premium, portfolio risk, and default — deterministic predictions, no prompt involved.

0 tokens · deterministic
Layer 3

LLM — only when needed

Reasoning tasks that genuinely need it, gated by per-job budgets and coverage thresholds — never for work code can already solve.

budgeted · accounted
~90%of typical pipeline tasks resolve deterministically
