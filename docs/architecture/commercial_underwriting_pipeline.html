05 · Decision logic

How the aggregate risk score is actually computed

Not a black-box probability — a weighted sum an underwriter can re-derive by hand from the findings in front of them.

score = Σ (severity_weight × confidence_weight) / n_findings + pile-up_bonus
  severity_weight = critical 1.00 · high 0.75 · moderate 0.50 · low 0.20
  confidence_weight = 0.5 + (finding confidence × 0.5)
  pile-up_bonus = min(0.15, volume amplification + high-risk category penalty)

decision =
  DECLINE — claim frequency ≥ 10/yr (hard gate, independent of score)
  REFER — any CRITICAL finding, or score ≥ refer threshold
  CONDITIONAL ACCEPT — moderate findings only, subjectivities attached
  ACCEPT — no findings requiring conditions

Environmental "data unavailable" findings never count toward the score — a missing loss run isn't the same risk signal as a disclosed one, and conflating the two is exactly the false-positive pattern this system had to fix. Findings are capped at HIGH unless a specific rule promotes them to CRITICAL, so no single fragile signal can auto-decline a file on its own.

07 · Data handling & storage

What's kept, what's encrypted, and what's never stored at all

WORKING STATE

Job progress lives in Redis (or in-memory in dev), keyed per organization, and expires in roughly a week. This is the "is the pipeline still running" state — not the record of what happened.

THE PERMANENT RECORD

The audit bundle and decision memory are Fernet-encrypted and written to the customer's own landing-zone disk, in WORM-pattern storage, for the retention window — a default of roughly seven years for sealed audit artifacts, matching examiner expectations.

WHAT'S NOT RETAINED

Source documents themselves are not kept for replay after the job completes — the policy admin system (Guidewire/BriteCore) is the system of record for the original files. This system stores the decision and its evidence trail, not a second copy of the submission.

WHAT NEVER REACHES AN LLM OR A LOG

The same PII redactor runs in two places: every prompt, streamed response, and embedding call is redacted before it leaves the process, and the identical redactor filters every application log line before it reaches stdout or CloudWatch — one redaction policy, not two to keep in sync.

The knowledge base the RAG layer searches is built from underwriting guidelines, not customer submissions — so a vector-search leak, if it ever happened, would expose reference material, not a policyholder's data.

09 · Reliability & trust

What happens when something goes wrong

The trust question isn't "does it work" — it's "what does it do when it doesn't." Every failure mode below defaults toward a human, never toward a silent accept.

If this fails……the system does this, not a silent default
Hallucination gate errorsFails closed: adds a CRITICAL finding, forces the decision to REFER, requires human review
A document is poor qualityDoc quality gate blocks straight-through processing and asks for resubmission rather than extracting garbage silently
A critical field is low-confidenceHeld for human confirmation below a 60% confidence floor — never priced on a guess
The dedicated pricing path throwsFalls back to generic pricing, but logs loudly and stamps the quote so the divergence is never invisible to the underwriter
A specialist agent errorsThat agent's result is marked failed; it does not silently drop out of the aggregate score
The LLM provider is downRetry logic distinguishes transient errors (timeout, 5xx, rate limit) from permanent ones (auth, bad request) — no infinite retry loop, no wasted spend on a dead credential

Reproducibility is a design constraint, not an afterthought: rating, scoring, and appetite decisions are deterministic — the same submission prices the same way twice — because that determinism is exactly what makes the audit trail worth trusting.

10 · What doesn't change

The sign-off stays human

Speed comes from removing the reading and re-checking, not the judgment.

What AI does

Extracts, cross-checks, and scores every document against loss bureaus, sanctions lists, CAT models, and the filed rate manual — in parallel, in minutes, and only reaches for a language model where a rule genuinely can't decide.

What the underwriter sees

A memo with every finding, its severity, and the exact document and page it came from — not a stack of raw ACORD forms, loss runs, and inspection reports to re-derive by hand.

What stays human

Accept, refer, decline, or price a condition — the recommendation is advisory. A licensed underwriter signs every decision, and can override or send it back for re-pricing at any point.
