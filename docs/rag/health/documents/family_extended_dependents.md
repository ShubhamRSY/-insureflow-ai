# Family Plan — Extended Dependent Coverage

**Line of business:** Health Insurance › Family Floater

**Effective:** 2026-01-01

## 1. Product overview

Family plan covering dependents to age 26 automatically, plus disabled adult dependents past 26 with certification on file.

## 2. Target market, appetite & eligibility

- **Market:** Family plans covering extended dependents (adult/disabled children).
- Dependents meeting ACA/plan dependency rules
- Disability documentation where applicable

## 3. Ineligible / decline criteria

- Dependents beyond the eligible age or relationship
- Missing disabled-dependent documentation
- Missing student-status verification
- Non-qualifying dependents added to the plan

## 4. Core submission packet (all products in this line)

- Government-issued photo ID (driver's license / passport / state ID)
- Social Security number (for exchange subsidy eligibility and carrier verification)
- Proof of address (utility bill / lease / bank statement)
- Date-of-birth verification (birth certificate / passport / driver's license)
- Completed application / enrollment form

## 12. Underwriting focus

No health-status underwriting on any covered member. Verify disability certification for any dependent past age 26.

## 13. Decline / refer authority

- Disabled adult dependents without documentation
- Dependents across state lines

- **Authority:** Major medical is guaranteed-issue. Supplemental lines carry medical/occupational authority to $100K benefit; above refers.
